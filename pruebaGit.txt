###1.

Git es un repositorio que se utiliza para el control de versiones y se utiliza para guardar los cambios en el código de un proyecto sin perder los anteriores.
 
###2.
git add : prepara los archivos para ser modificados o agregados en el repositorio.
git commit: guarda los archivos en el historial de cambios.
git push: publica los archivos en el repositorio remoto
Orden correcto: 1)git add archivoNuevo.js, 2)git commit -m "se sube el archivo archivoNuevo.js" y 3) git push archivoNuevo,js

###5.
Repositorio local: es una carpeta en mi computadora para guardar mis proyectos
Repositorio remoto: es una carpeta en un servidor remoto por fuera de mi computadora para guardar proyectos, por ejemplo: gitHub y fileZilla
